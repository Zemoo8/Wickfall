| What | Made how | Licence |

| Style reference image `ArtSource/Raw/A01_wickbearer_design_gemini_v1.jpg` | Generated with Google Gemini (the PDF's suggested tool), used only as a design reference, not shipped in the game | Gemini output, per Google's terms the user owns the output; reference only |
| Font "Wickfall Pixel" | Drawn by `Tools/font/make_font.py` | Made for the game (CC0) |
| Sound effects and music | Synthesized by `Tools/audio/make_audio.py` (no samples) | Made for the game (CC0) |
| Level layouts | Generated by `Tools/levels/*.py` | Made for the game |
| TextMesh Pro essentials | Unity package resources | Unity Companion License |
